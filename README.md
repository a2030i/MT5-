# 🇸🇦 مُرشد (Mursheed)

> منصة عربية ذكية تربط حسابات MetaTrader 5 بواجهة بسيطة وواضحة للمتداول العربي.

[![Status](https://img.shields.io/badge/status-MVP-yellow)]()
[![License](https://img.shields.io/badge/license-Proprietary-red)]()

---

## 🎯 الفكرة

MetaTrader 5 منصة قوية لكنها معقدة وغير عربية. **مُرشد** يأخذ كل قوة MT5 ويقدمها بواجهة عربية أنيقة وواضحة للمتداول العربي.

## ⚡ البدء السريع

### المتطلبات
- Docker و Docker Compose
- حساب في [MetaApi.cloud](https://metaapi.cloud) (مجاني للبداية)
- حساب MT5 من وسيط معتمد (للاختبار: استخدم Demo)

### التشغيل في 3 خطوات

```bash
# 1. انسخ ملف البيئة
cp .env.example .env

# 2. عبّ المتغيرات (خاصة METAAPI_TOKEN)
nano .env

# 3. شغّل المشروع
docker-compose up -d
```

### الوصول
- **الواجهة**: http://localhost:3000
- **API**: http://localhost:8000
- **توثيق API**: http://localhost:8000/docs

```
└──────────┬─────────────────┘

│  - JWT Authentication      │
│  - AES-256 Encryption      │
└──────────┬─────────────────┘
           │
    ┌──────┴───────┐
    │              │

│Postgres│   │  Redis   │
└────────┘   └──────────┘
           │
┌──────────▼─────────────────┐
│  MetaApi.cloud             │  ← الجسر مع MT5
└──────────┬─────────────────┘
           │
┌──────────▼─────────────────┐
│  MetaTrader 5 (آلاف        │
│  الحسابات سحابياً)          │
└────────────────────────────┘
```

### لماذا MetaApi.cloud؟
لأن `MetaTrader5` Python package الرسمية:
- تشتغل على Windows فقط
- تحتاج تيرمنال MT5 مفتوح ومسجل دخول
- اتصال واحد لكل تيرمنال (لا يصلح لمنصة سحابية)

MetaApi يحل كل هذا بـ REST API سحابي يدعم آلاف الحسابات بنفس الوقت.

## ⚠️ تنبيهات قانونية مهمة

### 🇸🇦 السوق السعودي
تقديم خدمات التداول في السعودية يتطلب:
- ترخيص من **هيئة السوق المالية (CMA)**
- التزام بـ **نظام حماية البيانات الشخصية (PDPL)**
- شراكة مع وسيط مرخص أو الحصول على ترخيص مستقل

**هذا المشروع نموذج تطويري — لا تستخدمه تجارياً قبل استشارة محامي متخصص.**

### 💰 المخاطر المالية
- التداول ينطوي على مخاطر فقدان رأس المال
- اختبر دائماً على حسابات Demo قبل الحقيقة
- لا تتداول بأموال لا تستطيع خسارتها
